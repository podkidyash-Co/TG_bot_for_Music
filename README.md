# Flowme

Telegram-бот, который составляет плейлисты по схожим трекам и плавно ведёт слушателя от текущего настроения к привычному.

## О проекте

Flowme — музыкальный помощник в формате чат-бота. Пользователь присылает ссылку на трек или вводит название трека или исполнителя, а бот находит этот трек в паутине — карте всех известных боту треков, где у каждого уже определены признаки (темп, жанр, язык, настроение и другие), — выбирает схожие композиции и собирает из них плейлист.

Главная идея — **плавность**. Обычные рекомендации часто бросают слушателя из одного настроения в другое. Flowme строит маршрут от трека к треку так, чтобы настроение менялось постепенно и приходило к тому, что пользователь привык слушать.

Бот также умеет рассказывать о треке и исполнителе, предлагать малоизвестную музыку и сохранять понравившееся.

## Для кого этот бот

- Возраст 16–25 лет.
- Слушает музыку по настроению, по 1–2 часа подряд: по дороге домой или на учёбу, на прогулке.
- Не знает, как искать новые треки.
- Не любит, когда музыка резко меняет настроение, и хочет, чтобы она плавно шла к привычному.

## Как это работает

```
                │        ПОЛЬЗОВАТЕЛЬ       │
                └─────────────┬─────────────┘
                              │
          ссылка на трек / название трека / исполнитель
                              │
                              ▼
                ┌───────────────────────────┐
                │    Трек есть в паутине?   │
                │ (проверка по хеш-таблице) │
                └───────┬───────────┬───────┘
                        │ да        │ нет
                        │           ▼
                        │  ┌─────────────────────────┐
                        │  │ Трек есть в скачанной   │
                        │  │ базе данных источника?  │
                        │  └───────┬───────────┬─────┘
                        │          │ да        │ нет
                        │          ▼           ▼
                        │  ┌──────────────┐ ┌──────────────────────┐
                        │  │ Классификация│ │ Запись в список      │
                        │  │ и добавление │ │ незарегистрированных │
                        │  │ в паутину    │ │ треков               │
                        │  └──────┬───────┘ └──────────┬───────────┘
                        │         │                    │
                        ◄─────────┘                    ▼
                        │                  Позже трек подтягивается
                        ▼                  из источника (если его нет
      ┌───────────────────────────┐        и там — не добавляется)

      │ Плейлист из схожих треков │
      └───────────────────────────┘
```

### Как трек попадает в паутину

Пользователь треки в паутину не добавляет. Добавлением занимается система администрирования, в будущем её заменит автоматическая. Когда пользователь обращается к треку, бот действует по шагам:

1. Проверяет через хеш-таблицу, есть ли трек в паутине. Если есть, сразу строит плейлист.
2. Если трека нет, ищет его в уже скачанной базе данных из источника и запускает алгоритм добавления в паутину (классификация по признакам и определение позиции).
3. Если трека нет и в базе, он записывается в список незарегистрированных треков. Позже его подтянут из источника, а если и там его нет, трек не добавляется.

### Паутина треков

Все треки образуют граф, который мы называем паутиной. Треки — это узлы, а чем больше два трека похожи по признакам, тем ближе они в паутине. Бот определяет, где находится трек пользователя, и прокладывает путь к целевому настроению. Каждый следующий трек в плейлисте лежит рядом с предыдущим, поэтому переходы получаются плавными.

```
  стартовый трек                                    целевое настроение
        ●───────●───────●                                  
                 \       \                                 
                  ●───────●───────●───────●───────●  ← путь плейлиста
                 /                         \
        ●───────●                           ●───────●
    (соседние узлы — близкие по звучанию треки)
```

### Признаки классификации

| Признак | Что описывает |
|---|---|
| Темп | скорость трека, bpm |
| Жанр | музыкальное направление |
| Язык | язык вокала |
| Тембр | окраска звука |
| Вокал | тип и характер голоса |
| Тональность / лад | мажор, минор и т.д. |
| Продакшн / эпоха звучания | время и стиль записи |
| Инструменты | какие инструменты есть в треке (бинарная система: есть / нет) |
| Энергия / интенсивность | насколько трек «заряженный» |
| Настроение | эмоциональная окраска |
| Смысл текста | о чём песня |
| Ритм / грув | характер ритмического рисунка |

Первый прототип алгоритма опирается на жанр, bpm, язык и год выхода. Остальные признаки добавляются поэтапно, а затем алгоритмы объединяются в один.

## Команды

### Доступные сейчас

| Команда | Описание |
|---|---|
| `/start` | Начало работы с ботом, приветствие и список команд |
| `/help` | Список доступных команд с описанием |
| `/help <command>` | Справка по конкретной команде |
| `/about` | Информация о боте и его назначении |
| `/author` | Авторы бота |

Часть команд скрыта и не показывается в `/help` (например, пасхалки). Список видимых команд собирается автоматически, ручная правка `/help` при добавлении команды не нужна.

### Планируются

| Команда | Описание |
|---|---|
| `/track` | Информация о треке, несколько самых популярных песен с введённым названием и кнопки 1 2 3 для выбора |
| `/similar` | Подбор похожих треков |
| `/artist` | Информация об исполнителе |
| `/random` | Случайный трек |
| `/who` | Малоизвестные треки и исполнители |
| `/playlist` | Составить плейлист |
| `/like` | Лайкнуть трек или исполнителя |
| `/help music` | Команды, связанные с музыкой |
| `/language` | Выбор языка бота |
| `/style` | Выбор стиля общения |
| `/discord` | Интеграция с Discord |

Также в планах «огонёчек» с ботом: серия дней, в которые пользователь слушает музыку.

## Составные части проекта

- **Клиенты источников данных** (`client/`) — обёртки над Last.fm, Spotify / YouTube Music и Shazam API. Используются для загрузки данных в локальную базу и для подтягивания незарегистрированных треков. Команды не знают, какой именно источник используется, поэтому источник можно заменить без переписывания хэндлеров.
- **Бот** (`telegram/FlowmeMusicBot`) — приём сообщений из Telegram и отправка ответов.
- **Система команд** (`telegram/command/`) — интерфейс `Command` и реализации команд. `CommandRouter` собирает все команды автоматически: новая команда попадает в роутер и в `/help` без ручной правки.
- **Ядро** (`core/`) — паутина треков с хеш-таблицей для быстрой проверки наличия трека, классификация и добавление треков в паутину, построение путей и плейлистов.
- **Система администрирования** — добавление треков в паутину; в будущем будет заменена автоматической.
- **Конфигурация** (`config/`) — токен бота и ключи API.
- **Тесты** (`src/test/`) — модульные тесты на JUnit 5.
- **База данных** (в планах) — скачанная база треков из источника, список незарегистрированных треков, пользователи, история запросов, лайки.
